### 🚀 Featured Project: Original Sound HQ Player

> *A modern, feature-rich hi-fi local music player built with WinUI 3 — supporting DSD, FLAC, WAV, MP3, AAC, M4A, AIFF, OGG, APE, Opus, WV and more.*

**Tech Stack:** `C#` `WinUI 3` `Windows App SDK` `Win2D` `BASS Audio`

**✨ Highlights:**
* **Hi-Fi Format Support:** Everything from **DSD** and **FLAC** to **APE, Opus and WV** — an audiophile-grade format arsenal in one native app.
* **DSP Suite:** Built-in **equalizer and convolution** processing for serious tuning.
* **Living Visuals:** Desktop lyrics, shader-rendered cover art and real-time spectrum effects powered by custom **Win2D** rendering.
* **A Real Music Library:** Albums, playlists and personal listening statistics.
* **Native & Polished:** A Fluent WinUI 3 experience built on the Windows App SDK.
